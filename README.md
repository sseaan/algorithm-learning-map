# ACM 算法地图

ACM 算法知识图谱、小测和本机学习记录。小测使用洛谷题目列表的标签与难度筛选；账号 UID 对应洛谷公开练习页中的 AC 题目列表。

## 本地运行

安装 Node.js 18 或更新版本，在仓库目录运行 node server.js，再打开 http://127.0.0.1:4173/。

## 在线部署

完整交互功能包含洛谷题库与 UID 核验 API，不能只用 GitHub Pages 托管。可将仓库导入 Netlify：选择本仓库并部署，`netlify.toml` 会自动配置静态页面、函数目录和 API 路由。也支持导入 Vercel，`api/` 下的函数提供 API，根目录的 `index.html` 作为网站入口。

仓库也保留 Render Blueprint 配置，可用于创建 Node Web Service。

## 数据

洛谷题库接口按知识点标签和节点难度上限随机抽题；题组在抽取后固定保存在当前浏览器。公开练习页提供的已通过题目用于自动核验。账号 UID、题组、状态和笔记都保存在浏览器 localStorage，不会上传到网站服务器或 GitHub。每位用户的数据只在该浏览器和网站域名下保留，不会跨设备同步。
